# Phase 1 Product Design Guide (Figma, You Run Everything)

## Goal
Define a clean UX for the learning experience before implementation.

## Why This Matters
Strong UX reduces confusion and makes technical learning paths stick.

## Step 1: Create Figma Project
Create one project named:
- Blocky Learning Platform

Create pages:
- Foundations
- Lesson Flow
- Dashboard
- Components

## Step 2: Design Critical User Flows
Design these flows end-to-end:
1. Onboarding to wallet connect
2. Lesson start to checkpoint submission
3. Failed checkpoint to remediation path
4. Completion to next module unlock

Pass criteria:
- every flow includes entry, system response, and success/failure state

## Step 3: Create Design Tokens
Define and name tokens in Figma:
- color
- type scale
- spacing
- radius
- elevation

Pass criteria:
- reusable styles/components applied across all frames

## Step 4: Prototype Interactions
Add prototype links for:
- next step transitions
- error modal behavior
- progress bar updates

Pass criteria:
- clickable prototype for at least one full learner journey

## Step 5: Handoff Pack
Create a handoff summary in product/ux-flows/ containing:
- screen inventory
- component list
- interaction notes
- open questions for implementation

## Step 6: Report Back
Share:
- Figma link
- list of completed flows
- unresolved UX questions
- screenshots of key screens
