# Docs-Only Mode Agreement

## Working Contract
You asked for this mode:
- I create and maintain Markdown documentation.
- You execute all non-doc actions (commands, installs, coding, deployments, dashboards, and integrations).

## How We Collaborate Per Task
1. You ask for the next milestone.
2. I provide:
- what to do
- why it matters
- exact commands to run
- expected outputs
- validation checklist
- rollback notes
3. You run it and share results.
4. I update docs and next-step instructions.

## Required Evidence You Should Share Back
For each completed step, paste:
- command output summary
- errors encountered and how you fixed them
- final status (pass/fail)
- any deviations from the documented steps

## Guardrails
- Never paste private keys, seed phrases, or production secrets into chat.
- Use testnet/local-only credentials for this project.
- If a step fails 3 times, stop and share full logs for a revised path.

## Done Criteria In Docs-Only Mode
A milestone is complete when:
- all commands executed successfully by you
- all listed validations passed
- progress log updated
- decision notes updated if architecture changed
