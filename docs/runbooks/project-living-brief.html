Blocky Project Living Brief

Snapshot date: 2026-06-09

What This Project Is

Blocky is a build-to-learn blockchain engineering lab. You are learning by shipping real software, not only reading theory.

The project combines two tracks:

  • Blockchain engineering track: protocol simulation, Solidity contracts, DeFi/NFT/marketplace modules, and multi-chain deployment.
  • Multi-learning software track: learner progress data model, analytics views, and BI dashboards.

Original Goal

Build a professional portfolio-grade system where you can explain blockchain internals, write safer smart contracts with tests, build product-facing learning flows, and measure outcomes with data and dashboards.
